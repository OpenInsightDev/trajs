# AGENTS.md

Each directory teaches one API.
`README.md` is the lesson; `main.test.ts` is the code.
`README.md` lists the tutorials.
Run one with `vp test <name>`, all with `vp test`.
A whole run read for what it asks is a case in `examples/traj-analysis`, not a tutorial.
