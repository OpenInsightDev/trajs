---
title: trajs
description: Produce, version and analyze trajectories of AI model sessions.
---

trajs treats an AI model session the way version control treats a working tree:
it produces a trajectory of what was asked, what the model returned, and which tools ran, then
keeps each revision so sessions can be replayed and compared later.
