A sheet is the dialog that comes from a side: `side` is which edge it is
anchored to, and the content slides in from it while the overlay dims what it
covered. It is what a narrow viewport shows where a wide one shows a panel, and
it carries the same title and description a dialog does.

A sheet is the same component the [Drawer](/components/drawer) adds a gesture
to; it is the one to reach for when the surface is opened by a button rather
than by a thumb.
