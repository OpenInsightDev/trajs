A hover card is read without a click, so it previews rather than acts: the
content is the card, and whatever it is anchored to stays where it is. It opens
on hover and on focus, which is what makes it reachable by keyboard too.

Anything a card can say, a hover card can preview; anything that has to be
clicked is a [Popover](/components/popover), since a card leaves when the
pointer does.
