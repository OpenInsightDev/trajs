---
title: Breadcrumb
description: Where a page sits, as the path that reaches it.
---

import {
  Breadcrumb,
  BreadcrumbEllipsis,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbList,
  BreadcrumbPage,
  BreadcrumbSeparator,
} from "@trajs/ui-shadcn/breadcrumb";

The list is an ordered one, so a breadcrumb is read as the path it is rather
than as a row of links. The page a reader is on is `BreadcrumbPage` — unlinked,
because it is where they already are — and the separator between steps is a
chevron unless the page gives its own.

<Preview>
  <Breadcrumb>
    <BreadcrumbList>
      <BreadcrumbItem>
        <BreadcrumbLink href="#">Sessions</BreadcrumbLink>
      </BreadcrumbItem>
      <BreadcrumbSeparator />
      <BreadcrumbItem>
        <BreadcrumbEllipsis />
      </BreadcrumbItem>
      <BreadcrumbSeparator />
      <BreadcrumbItem>
        <BreadcrumbLink href="#">2026-10-17</BreadcrumbLink>
      </BreadcrumbItem>
      <BreadcrumbSeparator />
      <BreadcrumbItem>
        <BreadcrumbPage>session_8f2a</BreadcrumbPage>
      </BreadcrumbItem>
    </BreadcrumbList>
  </Breadcrumb>
</Preview>

`BreadcrumbEllipsis` is what a path too long for the row folds into: the steps
between are still reachable, and the row stays one line.
