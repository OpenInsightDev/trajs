---
title: Separator
description: A rule between two things.
---

import { Separator } from "@trajs/shadcn/separator";

A separator is the line itself and nothing around it — no margin, no colour
beyond the border token — so the page that places it owns the space. The
orientation is the direction of the line, not of the things it separates.

A vertical separator stretches to the height of what it is in, which is what
makes it read as a divider between columns rather than a mark on one.
