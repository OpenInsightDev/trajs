import {
  Attachment,
  AttachmentAction,
  AttachmentActions,
  AttachmentContent,
  AttachmentDescription,
  AttachmentGroup,
  AttachmentMedia,
  AttachmentTitle,
} from "@trajs/shadcn/attachment";
import { FileTextIcon, XIcon } from "lucide-react";

An attachment is one file: the media it is previewed by, the title and the
description it is named and sized by, and the actions beside it. Its `state` is
what it is doing — `idle` for one not uploaded, `uploading` and `processing`
while a name shimmers, `error` for one that did not arrive — and the border says
that state before any text does.

`AttachmentTrigger` covers an attachment whole, which is what a file that opens
somewhere is: the content stays selectable and the click belongs to the trigger.
