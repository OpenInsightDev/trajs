import {
  Card,
  CardAction,
  CardContent,
  CardDescription,
  CardFooter,
  CardHeader,
  CardTitle,
} from "@trajs/shadcn/card";
import { Button } from "@trajs/shadcn/button";

A card is a ring and one spacing value, which is what makes its parts line up
without any of them naming a padding. `CardHeader` holds the title, the
description and the one `CardAction` in its corner, `CardContent` is the body,
and a `CardFooter` is the row a card is answered in.

      <CardContent>The response stopped before its end.</CardContent>
      <CardFooter>
        <Button size="sm" variant="outline">
          Resume
        </Button>
      </CardFooter>
    </Card>
  </div>
</Preview>

`size="sm"` tightens the spacing and the title with it, for the cards that sit in
a list rather than standing alone. An image as the first or last child is
rounded to the card's own corners, so a card that leads with one needs no
classes to keep it inside.
