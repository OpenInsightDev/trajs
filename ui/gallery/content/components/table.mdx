---
title: Table
description: Rows of the same columns, compared down a column.
---

import {
  Table,
  TableBody,
  TableCaption,
  TableCell,
  TableFooter,
  TableHead,
  TableHeader,
  TableRow,
} from "@trajs/ui-shadcn/table";

A table is the columns the rows are read in: the header names them, the body
holds them, and the footer is the row a table totals itself in. Rows hover and
say when they are selected from their own state, which is what makes a long one
trackable across the width of it.

A narrow surface gets the table scrolled sideways rather than wrapped, since a
column that folds into two lines stops being comparable with the one above it.
