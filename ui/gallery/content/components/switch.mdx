---
title: Switch
description: A setting that is on or off, applied at once.
---

import { Switch } from "@trajs/ui-shadcn/switch";
import { Label } from "@trajs/ui-shadcn/label";

A switch takes effect when it is thrown, which is what tells it apart from a
checkbox: nothing is submitted for it. Its two states are the two the tokens
paint, and the thumb slides between them.

A choice that is only recorded when a form is submitted is a
[Checkbox](/components/checkbox) instead.
