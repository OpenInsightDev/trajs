The design language is [`ui/shadcn/styles.css`](https://github.com/OpenInsightDev/trajs/blob/main/ui/shadcn/styles.css):
the light and dark values of every semantic token, the `@theme inline` mapping
that turns them into Tailwind utilities, and the base layer that applies them.

It is project code, not a copied source — the `shadcn add` CLI never touches it —
and it is exported as `@trajs/ui-shadcn/styles.css`. An app imports it once, after
Tailwind:

```css
@import "tailwindcss";
@import "@trajs/ui-shadcn/styles.css";
```

## Why the components have no colour of their own

Every component in the library is written against `--background`, `--foreground`,
`--primary`, `--muted`, `--destructive`, `--border`, `--ring` and `--radius`.
None of them defines a colour. That is what lets one stylesheet repaint all of
them, and it is what makes this page worth reading before changing one: a token
edited below moves every component at once.
